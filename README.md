# 🎬 ReelForge

**Turn scripts into stunning vertical videos — right from your Windows PC.**

[![Release](https://img.shields.io/github/v/release/MaLickAsif/ReelForge?style=flat-square)](https://github.com/MaLickAsif/ReelForge/releases/latest)
[![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-blue?style=flat-square)](https://github.com/MaLickAsif/ReelForge/releases/latest)
[![License](https://img.shields.io/badge/license-Proprietary-red?style=flat-square)](#license)

ReelForge is a desktop app for faceless video creators. Write a script, pick a voice, choose a format — ReelForge renders a complete 1080×1920 video with AI visuals, natural voiceover, and karaoke-style subtitles. Everything runs locally on your machine.

### Installation

1. Download `ReelForge-Setup-1.0.0.exe` above
2. Run the installer and follow the steps
3. Launch ReelForge from the Start menu or desktop shortcut
4. Sign up with your Gmail account and verify your email — you're in

### System requirements

| | |

## ✨ Features

- **📝 Script to video** — paste a script or import a text file; ReelForge splits it into scenes automatically
- **🖼️ AI visuals** — cinematic 9:16 images generated per scene
- **🎙️ Natural voices** — 55+ voices including offline Kokoro TTS and Edge TTS (Urdu `ur-PK` supported)
- **💬 Karaoke subtitles** — word-timed, styled captions burned into the video
- **📐 Multiple formats** — 9:16 Reels/Shorts/TikTok, 16:9 YouTube, 1:1 square
- **🔐 Gmail sign-in** — secure account with mandatory email verification
- **🌗 Light & dark themes** — easy on the eyes, day or night
- **🔄 Auto-updates** — new versions install in one click

## ❓ FAQ

**Is ReelForge free?**
ReelForge v1.0.0 is free to download and use. An account (Gmail) is required.

**Why Gmail only?**
To keep sign-ups simple and spam-free. Only `@gmail.com` addresses are accepted.

**I didn't get the verification email.**
Check your spam folder. The email comes right after sign-up — click the link, then log in.

**Does it work offline?**
Sign-in and AI generation need internet. Kokoro voices work offline once the model is downloaded inside the app.

**Which Windows versions are supported?**
Windows 10 and 11, 64-bit.
